## Как скачать и запустить

1. Скачайте **Russificator-win64.zip** ниже (раздел «Assets»).
2. Распакуйте архив в любую папку (например, «Документы\\Русификатор»).
3. Запустите **Russificator.exe**. Если Windows покажет «Система Windows защитила ваш компьютер» —
   «Подробнее» → «Выполнить в любом случае» (программа без цифровой подписи).

Нужна Windows 10 или 11 (64 бита).

## Что нового в 2.2.1

Исправления по отзывам игроков.

**Живой перевод**
- Перевод больше не получается крупнее оригинала и не налезает на соседние строки: размер
  считается по буквам самой строки (раньше — вместе с задетой соседней, в полтора-два раза больше).
- Поверх перевода больше не проступают куски английских букв соседних надписей.
- Старый перевод не задерживается на экране, когда текст сменился другим того же цвета.
- Плавно проявляющийся текст переводится сразу, а не через полторы секунды.

**Машинный перевод**
- Ошибка «NOT_FOUND … source.spm: No such file or directory», если в пути к программе есть русские
  буквы (например, папка пользователя «Игорь»). Уже скачанная модель подхватится без повторной загрузки.
- Строки с тегами и подстановками (`{0}`, `[player]`, `<color>`) снова переводятся целиком, а не
  кусками; значки (`= ~ → | ♥ ★`) остаются на месте вместо «⁇»; к непереводимым словам больше не
  дописывается «(англ.)».

**Окно программы**
- Программа больше не зависает при закрытии («не отвечает»).
- После отката русификации кнопка «Откатить» и статус «Игра на русском» сразу исчезают.
