## Как скачать и запустить

1. Скачайте **Russificator-win64.zip** ниже (раздел «Assets»).
2. Распакуйте архив в любую папку (например, «Документы\\Русификатор»).
3. Запустите **Russificator.exe**. Если Windows покажет «Система Windows защитила ваш компьютер» —
   «Подробнее» → «Выполнить в любом случае» (программа без цифровой подписи).

Нужна Windows 10 или 11 (64 бита).

## Что нового в 2.4.0

**Важно, если игра перестала слушаться после русификации.** Старые игры на Unity 5 (например, Crawl)
после русификации прошлыми версиями могли не реагировать на клавиши в главном меню: при дописывании
русских букв в шрифты портились соседние данные игры. Исправлено, и теперь каждый изменённый файл
перепроверяется перед записью — если хоть что-то в нём сдвинулось, файл игры не трогается. Если у вас
так случилось: «Откатить» в программе, затем русифицировать заново этой версией.

**Русские буквы в пиксельных шрифтах**
- В мелких пиксельных шрифтах (буквы в 4–8 точек) русские буквы собираются из латиницы самого шрифта,
  точка в точку: «И» — из «N», «Я» — из «R», «Ж» — из «K». Раньше Ж, Ф, Ш, Ы в таких шрифтах
  расплывались в кляксы.
- Буквы в игре больше не «плывут», кратка над «Й» не налезает на соседнюю строку меню.
- Шрифты ex2D (старые 2D-игры на Unity) тоже получают русские буквы.

**Перевод полнее и грамотнее**
- Фраза, которую игра разбила на строки ради вёрстки («insert / coin»), переводится целиком
  («вставить монету», а не «вставить монета») и раскладывается на те же строки — при любом способе
  перевода. Строки, переведённые прошлыми версиями по кусочкам, при повторной русификации
  переводятся заново, остальное берётся готовым.
- Названия в Заглавном Регистре и КАПСОМ переводятся, а не остаются английскими
  («Shattered Roost» → «Разбитое гнездо», «LEVEL 7» → «уровень 7»).
- Одиночные буквы, инициалы и окончания («A B C D» на экране ввода имени, «DAP», «2ND») остаются как
  в игре — раньше вместо них появлялся набор русских букв.
- «-NEW-», «[ OK ]» и подобные слова в рамке из знаков переводятся по словарю интерфейса.
- Переводятся строки, которые игра собирает сама: с числом («+2 Vitality», «Level 7»), короткие
  подписи с числами («0 / 45 завершено»), текст, который игра сама переносит по ширине.

**Unity: перевод в самой игре**
- Надписи, которые игра обновляет каждый кадр (кнопки, мигающие подписи), больше не остаются
  английскими.
- Текст в TextMesh (у него нет своего переноса) переносится по ширине английского и не уходит за
  край экрана.
- Тексты ex2D переводятся.
- Исправлен «мусор» вместо букв в надписях, которые были скрыты, когда игра дорисовывала новые буквы
  в шрифт (например, невыбранный пункт меню).
- Если в игре выключить перевод (Alt+T), программа ничего не подменяет; сбой любой части модуля
  перевода выключает только эту часть — игра продолжает работать.
