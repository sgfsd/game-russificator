# Русификатор игр

**Автоматическая русификация PC-игр на Unity, Ren'Py и RPG Maker — и живой перевод поверх любых других игр.**
Выберите игру из списка (или её папку), выберите способ перевода, нажмите кнопку — и получите
русскую версию. Движок определяется сам, оригинальные файлы сохраняются,
откат — одной кнопкой. Готовый перевод можно упаковать в архив с установщиком и отправить другу.

Программа некоммерческая и работает на вашем компьютере: без регистрации,
без посредников и без отправки файлов игры куда-либо.

**Автор:** Telegram [@TRAPYCHINO](https://t.me/TRAPYCHINO) — вопросы, ошибки, заказ качественного перевода.

## Скачать

1. Откройте [Releases](../../releases) и скачайте `Russificator-win64.zip`.
2. Распакуйте в любую папку (лучше не в `Program Files`) и запустите `Russificator.exe`.

Нужна Windows 10/11 (64-бит). Python не нужен. Все модели и настройки хранятся
рядом с программой, в папке `RussificatorData`. Чтобы удалить программу, удалите её папку.

## Как пользоваться

1. **Игра**: выберите её во вкладке **«Мои игры»** или кнопкой «Обзор…» укажите корень игры
   (где лежит `.exe`). Программа покажет движок.
2. **Способ перевода**: одна из четырёх плиток (ниже).
3. **«Русифицировать»**: программа найдёт текст, переведёт, встроит перевод и
   исправит шрифты. Перевод можно остановить — при следующем запуске он продолжится
   с того же места. Уже переведённое запоминается и повторно не переводится.

После русификации игру можно запускать как обычно. Кнопка **«Откатить»**
возвращает игру в исходное состояние. В игре **`Alt+T`** переключает перевод и оригинал
(Unity, Ren'Py, RPG Maker MV/MZ — реплики и выборы).

## Русификатор для друзей

После русификации нажмите **«Создать файл русификатора»** — в выбранной папке появится
`<Игра> — русификатор.zip`. Отправьте его другу: он распакует архив, запустит
`Установить.exe` — установщик сам найдёт игру (Steam, GOG, Epic…) и поставит перевод.
Программа другу не нужна; удалить русификатор можно тем же установщиком.

- Файлов игры в архиве нет: только добавленное русификатором, бинарные патчи изменённых
  файлов и сам перевод — архив маленький.
- Другая версия игры у друга не ломается: RPG Maker переводит всё совпавшее (новые строки
  остаются английскими), Unity и Ren'Py ставят словарь как есть.
- По желанию в главном меню игры появится небольшая надпись «Автоперевод: Русификатор игр ·
  ручной перевод — tg @TRAPYCHINO» (во время игры её нет).
- Готовый архив можно поставить и из программы: «Мои игры» → «Установить русификатор из архива».

## Мои игры

Вкладка сама находит установленные игры: Steam (все библиотеки), GOG, Epic, Ubisoft Connect,
itch.io, Game Pass, игры из списка программ Windows и из ваших папок (Настройки → «Папки для
поиска игр»). У каждой — обложка, движок и состояние: *на русском*, *перевод слетел после
обновления* (кнопка «Переустановить перевод» — готовые строки возьмутся из памяти), *можно
русифицировать* или *только живой перевод*. Отсюда же — «Играть», «Откатить», ярлык и архив
для друзей. Игры нет в списке — «Добавить папку игры».

## Живой перевод поверх любой игры

Включите **«Живой перевод»** один раз — программа будет ждать в трее и, как только на экране
игра, распознавать **всё, что на нём написано**, и показывать перевод поверх оригинала:
интерфейс и диалоги, надписи на картинках и текстурах, кнопки-картинки, пиксельные и
стилизованные шрифты. Подходит для любых игр (Unreal, Godot, Game Pass, онлайн-игры), а в играх,
русифицированных файлами, дополняет перевод: русский текст не трогает, переводит то, что
осталось на английском (заставки, таблички, надписи на текстурах).

- Перевод встаёт **на место** английского текста — в том же цвете и похожем шрифте, того же
  размера (у похожих надписей игры — один размер, без «прыжков»); длинный русский текст занимает
  свободный фон рядом, а не мельчит.
- Работает по событиям: неподвижный экран распознаётся один раз, распознаётся только та часть
  кадра, где сменился текст, перевод — по предложениям. Поэтому перевод на экране не «мигает» и не
  меняется сам по себе: он появляется один раз, когда текст допечатан, и исчезает сразу после
  того, как реплика пропала. Повторяющийся текст (меню, подсказки) — сразу из памяти переводов.
- Анимированный текст (дрожь, глитч, переливы), мигающий значок «дальше», анимированный фон и
  логотипы не сбивают перевод и не превращаются в мусор на экране.
- Работает в оконном режиме, «окне без рамки» и полноэкранном режиме Windows 10/11: если игра не
  отдаёт картинку со своего окна, кадр берётся с экрана, а окно перевода исключается из захвата.
- Надписи на картинках, мелкий и стилизованный текст: распознавание — нейросеть PP-OCRv5 (на
  видеокарте или процессоре — что быстрее на этом ПК); когда экран замирает, кадр распознаётся
  ещё и в полном разрешении. Ошибки распознавания исправляются по словарю («sraphic» → «graphic»).
- Не переводятся: русский текст (в том числе русификация самой игры), заголовок окна, названия
  движков и площадок («Made with Unity», «Discord», «Patreon»), логотип игры, имя героя
  табличкой над репликой.
- Игра определяется сама: «Мои игры», игры, которые знает игровая панель Windows, игры в окне с
  файлами движка рядом с exe (Unity, Ren'Py, RPG Maker, Unreal, Godot…) и любые окна на весь
  экран. Браузеры, мессенджеры, плееры и банковские программы не распознаются никогда. Ошиблась —
  списки «Всегда»/«Никогда»; игра не распозналась — «Переводить окно…» в меню значка в трее или
  на вкладке.
- `Alt+T` — показать/скрыть перевод, `Alt+Y` — перевести сейчас, `Alt+R` — обвести мышью
  область текста (например, только окно диалогов; запоминается для игры). Клавиши работают
  только пока на экране игра.
- Скорость: новая фраза с машинным переводчиком — доли секунды (на старом ПК — около секунды),
  с нейросетью на ПК — столько, сколько нейросеть переводит фразу (на слабой видеокарте —
  секунды). Замеры этого ПК видны на вкладке «Живой перевод».

## Способы перевода

| | Способ | Для кого | Что нужно |
|---|---|---|---|
| 1 | **Машинный переводчик** (Argos Translate, офлайн) | любой, даже очень старый ПК | ~200 МБ, 2 ГБ ОЗУ |
| 2 | **Нейросеть на компьютере** (Gemma 4 через llama.cpp) | ПК с 8+ ГБ ОЗУ или видеокартой | 2,6–7 ГБ на диске |
| 3 | **Облачная нейросеть** по вашему API-ключу | любой ПК с интернетом | ключ провайдера |
| 4 | **Заказать перевод у автора** — ручная вычитка | кому нужно качество «как у студии» | Telegram [@TRAPYCHINO](https://t.me/TRAPYCHINO) |

**Машинный переводчик** скачивается один раз и работает без интернета. Самый быстрый
и нетребовательный способ, но перевод дословный.

**Нейросеть на компьютере** переводит с учётом контекста (кто говорит, соседние реплики).
Программа сама скачает модель и подберёт её под ваше железо:

| Модель | Размер | Подойдёт |
|---|---|---|
| Gemma 4 E2B — лёгкая | 2,6 ГБ | ноутбуки, ПК с 8 ГБ ОЗУ |
| Gemma 4 E4B — оптимальная | 4,2 ГБ | 16 ГБ ОЗУ или видеокарта 6+ ГБ |
| Gemma 4 12B — лучшая | 7,0 ГБ | видеокарта 10+ ГБ |

Работает на видеокартах NVIDIA, AMD и Intel (Vulkan), без видеокарты — на процессоре (медленнее).
Можно указать и свой `.gguf`-файл.

**Облачная нейросеть**: выберите провайдера, вставьте ключ, нажмите «Обновить список» —
программа покажет актуальные модели, подходящие для перевода — первыми. Рекомендации:

| Провайдер | Почему |
|---|---|
| DeepSeek | дёшево и отлично знает русский |
| Google Gemini | есть бесплатный дневной лимит |
| OpenRouter | сотни моделей по одному ключу, есть бесплатные (`:free`) |
| OpenAI, Anthropic, Mistral | высокое качество |
| Ollama, LM Studio | своя модель на своём ПК |
| Другой | любой OpenAI-совместимый API: адрес `…/v1`, ключ, модель |

Ключ хранится только на вашем компьютере в зашифрованном виде (Windows DPAPI) и
отправляется только выбранному провайдеру.

## Движки

| Движок | Что переводится | Как встраивается |
|---|---|---|
| **Unity** (Mono и IL2CPP) | весь текст интерфейса и диалогов, в том числе собранный игрой на лету; диалоги в текстовых ассетах (JSON, CSV, XML, Ink, Yarn); страницы встроенного браузера (ZFBrowser) | BepInEx + XUnity.AutoTranslator, словарь перевода и плагин русификатора; файлы игры не правятся (кроме шрифтов и страниц браузера) |
| **Ren'Py** | реплики, рассказчик, меню выбора, `_()`-строки, имена, надписи экранов, `renpy.notify`/`input`/`Confirm`…; скрипты `.rpy`, `.rpyc`, архивы `.rpa` | отдельный файл перевода + фильтр текста в игре; исходники не меняются |
| **RPG Maker MV / MZ** | сообщения, выборы, прокрутка текста, база данных, термины, названия карт, надписи плагинов (`plugins.js`, команды плагинов MZ), `$gameMessage.add` в скриптах | прямо в `data/*.json` и `js/plugins.js` + плагин переноса слов |
| **RPG Maker XP / VX / VX Ace** | то же (Ruby Marshal), в том числе из архивов `.rgssad`/`.rgss2a`/`.rgss3a`, плюс надписи в скриптах игры (модуль `Vocab`, команды меню) | в `Data/*.rxdata`/`.rvdata`/`.rvdata2` и `Data/Scripts.*` |

**Шрифты.** Почти все западные игры рисуют текст шрифтами без кириллицы — русские
буквы превращаются в «квадратики». Программа проверяет каждый шрифт игры и сама
добавляет недостающие русские буквы: в атласы TextMeshPro и растровые шрифты Unity
(подгоняя их под стиль и размер оригинала), подменяет шрифты Ren'Py и RPG Maker на
PT Sans.

**Русский текст длиннее английского** — и за этим программа следит на каждом движке:

- **Unity:** плагин русификатора прямо в игре проверяет каждый переведённый элемент
  и, если текст вылезает за рамку или рвёт слово, уменьшает шрифт (не мельче 60%).
- **RPG Maker:** строки сообщений переносятся по ширине окна в пикселях (по метрикам
  шрифта, с учётом лица персонажа, иконок и имён). В MV/MZ плагин русификатора ещё и
  в игре переносит слово, которое не влезло, а описания предметов и строки боя
  уменьшает; в VX Ace длинные описания разбиваются на две строки заранее.
- **Ren'Py:** если реплика не помещается в окно диалога, её шрифт уменьшается ровно
  настолько, чтобы влезла.

Пока текст помещается, ничего не меняется.

**Непереведённого не остаётся.** Строки, которые переводчик не осилил с первого раза
(сбой сети, сломанная разметка), переводятся ещё раз по одной, затем по кускам между
тегами и, если скачан машинный переводчик, им как запасным.

### Особенности Unity

- **Заранее переводится всё, что можно найти:** текст сцен и ассетов, строки кода, а ещё
  шаблоны, которые игра собирает сама («You have {0} coins», «Day » + n + « of » + m) —
  они становятся правилами XUnity и переводятся без интернета и без программы.
- **Живая доводка** — редкий текст, которого не было нигде (собранный кодом на лету),
  переводится прямо во время игры и запоминается (сколько таких строк — видно в «Моих играх»).
  Она включается сама, как бы игру ни запустили — из Steam, ярлыком или exe: плагин
  русификатора (Mono — BepInEx 5, IL2CPP — BepInEx 6) при старте игры запускает программу в
  фоне и закрывает её вместе с игрой. Не перемещайте и не удаляйте папку русификатора
  (перенесли — русифицируйте игру ещё раз, готовый перевод возьмётся из памяти).
- При первой русификации Unity-игры скачиваются BepInEx и XUnity.AutoTranslator
  (1,5 МБ, для IL2CPP-игр — больше; один раз на все игры).
- IL2CPP-игры запускаются с BepInEx первый раз 1–5 минут — это нормально.
- В игре `Alt+T` переключает оригинал/перевод.

## Ограничения

- Текст, нарисованный на картинках (вывески, таблички, логотипы), файловая русификация не
  переводит — его переводит живой перевод поверх игры.
- Игры с шифрованием или защитой от модификаций могут не поддаваться файловой русификации —
  для них есть живой перевод поверх экрана.
- RPG Maker 2000/2003, Unreal, Godot, GameMaker пока не поддерживаются файлами (только живой перевод).
- Живой перевод не видит игру в «настоящем» эксклюзивном полноэкранном режиме, который Windows не
  умеет оптимизировать (например, OpenGL на видеокартах AMD): поверх такой игры не может рисовать
  ни одна программа без внедрения в неё — программа подскажет включить «окно без рамки». Сильно
  стилизованные надписи (штампы, логотипы) распознавание может не прочитать — тогда они остаются
  как есть.
- Машинный перевод — черновой; для хорошего результата выбирайте нейросеть,
  для идеального — заказ перевода у автора.

## Запуск из исходников

Нужен Python 3.10+ (проверено на 3.14).

Окно программы — двойной клик по **`start.bat`**: при первом запуске он сам создаёт
окружение `.venv` и ставит в него компоненты (нужен интернет, несколько минут), дальше
сразу открывает программу. `Русификатор.pyw` тоже работает — если его открыл «не тот»
Python, он перезапустится через `.venv`.

Вручную:

```bash
python -m venv .venv
.venv\Scripts\python -m pip install -c requirements-lock.txt -e .
.venv\Scripts\pythonw Русификатор.pyw
```

Командная строка (из `.venv`):

```bash
russificator detect "C:/Games/MyGame"
russificator run "C:/Games/MyGame"                                   # машинный перевод
russificator run "C:/Games/MyGame" --mode local --local-model gemma4-e4b
russificator run "C:/Games/MyGame" --mode cloud --provider deepseek --api-key КЛЮЧ
russificator models --provider gemini --api-key КЛЮЧ                  # модели провайдера
russificator play "C:/Games/MyGame"                                  # Unity: игра + живой перевод
russificator restore "C:/Games/MyGame"
russificator export "C:/Games/MyGame" --out "D:/Русификаторы"        # архив для друзей
russificator install "D:/MyGame — русификатор.zip" "C:/Games/MyGame"
russificator games                                                   # установленные игры
```

Тесты: `pytest`. Устройство программы — в [docs/HOW-IT-WORKS.md](docs/HOW-IT-WORKS.md).

### Сборка exe

Сборка идёт на серверах GitHub ([.github/workflows/build.yml](.github/workflows/build.yml)):
отправьте тег (`git tag v2.1.0 && git push --tags`) — прогонятся тесты, соберутся
установщик для архивов (`installer.spec` → `RussificatorSetup.exe`) и `Russificator.exe`,
пройдут самопроверку, и программа появится в Releases архивом `Russificator-win64.zip`.
Локально: `pyinstaller installer.spec`, затем `pyinstaller russificator.spec` → `dist/Russificator/`.

Та же сборка запускается вручную (Actions → build → Run workflow) с любой ветки — архив
остаётся в артефактах. Заодно проверяется вживую:
- живой перевод на настоящей Windows (`tools/ci_overlay_check.py`): распознавание текста
  обоими способами, окна оверлея, сквозной путь «полноэкранная игра → перевод → плашка»;
- установщик ставит и удаляет русификатор в тестовую игру (`--selftest`);
- Ren'Py 8 и 7 (`tools/ci_renpy_check.py`): демо-игра из SDK русифицируется, ставится
  архивом «для друзей», проходит lint и запускается — надпись, реплики, Alt+T.

Плагины Unity (`resources/unity/*.dll`) собираются из `RussificatorUnity.cs` скриптом
`python tools/build_unity_plugins.py` (нужен `mcs` из Mono или `csc` из .NET Framework).
